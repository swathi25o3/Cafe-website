# Rainforest Café

A responsive, frontend-only website for a fictional forest-themed café with a cosy, woodsy feel.

**Live site:** https://swathi25o3.github.io/Cafe-website/
**Repository:** https://github.com/swathi25o3/Cafe-website

## Project overview

**Idea:** Rainforest is a cabin-in-the-woods café serving warm drinks and fresh bakes in a calm, cosy setting.

**Purpose:** Let visitors learn the café's story, browse the menu, find the address and hours, and request a table.

**Target audience:** Students, book lovers, friends and couples looking for a quiet, warm place to relax.

## Design

- Palette: deep forest green, cream, bark brown and a warm lantern-gold accent
- Fonts: Fraunces (headings) and Nunito (body text)
- Hero: a pine tree silhouette with softly glowing fireflies

## Features

- Responsive layout for desktop, tablet and mobile
- Hamburger navigation menu on small screens
- Auto-playing carousel of house favourites with previous/next buttons and dots
- Menu filter buttons (All, Coffee, Tea & cocoa, Bakes)
- Table request form with client-side validation
- Visible keyboard focus and reduced-motion support

## Technology stack

- HTML5
- CSS3 (custom properties, flexbox, grid, media queries, keyframe animation)
- Vanilla JavaScript
- Google Fonts
- Hosted on GitHub Pages

## Project structure

```
index.html   page structure and content
style.css    design, layout and responsive rules
script.js    navigation, carousel, menu filter, form validation
README.md    project documentation
```

## Setup instructions

1. Clone the repository:
   ```
   git clone https://github.com/swathi25o3/Cafe-website.git
   ```
2. Open the folder:
   ```
   cd Cafe-website
   ```
3. Open `index.html` in any modern browser. No build step is needed.

## Deployment (GitHub Pages)

1. Push the code to the `main` branch.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The live link appears on that page after about a minute.

## Note

This is a frontend-only project. The table request form does not send data anywhere.
